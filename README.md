## Project Overview

This project is a relational database system designed to simulate Uber's ride-sharing operations using SQLite.

The database manages riders, drivers, vehicles, trips, and payments. It also includes SQL analytical queries to evaluate driver performance, trip activity, and revenue generation.

## Database Tables

1. **Riders** – Stores rider information, including names, phone numbers, and email addresses.
2. **Drivers** – Stores driver information, license numbers, and ratings.
3. **Vehicles** – Stores vehicle information and associates vehicles with drivers.
4. **Trips** – Records ride information, pickup and drop-off locations, trip times, and trip statuses.
5. **Payments** – Records payment amounts, payment methods, and payment dates.

## Database Relationships

- One rider can request multiple trips.
- One driver can complete multiple trips.
- One driver can be associated with multiple vehicles.
- Each trip is assigned to one rider and one driver.
- Each trip can have at most one payment record.

## SQL Analytics

The project includes five analytical queries:

1. Total revenue generated by each driver.
2. Average driver rating comparison.
3. Completed, cancelled, and in-progress trip counts.
4. Top-earning drivers using the HAVING clause.
5. Daily revenue generated from completed trips.

These queries demonstrate SQL concepts including JOIN, GROUP BY, SUM, AVG, COUNT, WHERE, HAVING, and ORDER BY.

## Project Files

- `schema.sql` – Creates the database tables and relationships.
- `seed.sql` – Inserts sample records into the database.
- `queries.sql` – Contains five analytical SQL queries.
- `uber.db` – SQLite database containing the project data.

## How to Run

1. Install DB Browser for SQLite.
2. Open `uber.db` using DB Browser.
3. Navigate to the Execute SQL tab.
4. Open `queries.sql`.
5. Execute the SQL queries to view the analytical results.

To rebuild the database from scratch, create a new empty SQLite database, execute `schema.sql`, and then execute `seed.sql`.
